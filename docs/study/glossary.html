    term meaning page
    ACE, mL1-ACE average calibration error: mean over non-empty bins of |mean p - mean y|; mL1 = averaged over classes, used as a loss 1
    hard / soft binning each voxel in one bin / spread over the two nearest bin centres with linear weights (smooth in p) 1
    calibration predicted probabilities match observed frequencies 1
    memory-bound time set by bytes moved, not arithmetic; the limit is bandwidth (T4: 320 GB/s) 1
    bandwidth floor ideal bytes / peak bandwidth: the fastest possible time 7
    roofline comparing measured performance with the hardware's compute and bandwidth limits 1
    % of peak bandwidth ideal bytes / measured time / peak bandwidth 7
    launch overhead, launch-bound ~5 us CPU cost per GPU kernel; a call is launch-bound when that dominates 5
    kernel one GPU program launch 4
    atomic add, contention indivisible read-modify-write; threads hitting the same address serialize 1
    privatization each block accumulates in private registers and publishes once 4
    Triton program, block, grid one instance of a kernel; the vector of elements it handles; all instances 4
    constexpr compile-time kernel argument; branches on it cost nothing at run time 4
    autotune trying several block sizes on first call, keeping the fastest 4
    fusion doing several steps in one kernel so data is read once 4
    recompute vs store redo cheap work in backward instead of keeping tensors in memory 3
    saved tensors what autograd keeps between forward and backward 3
    subgradient, kink derivative of |x| at 0 is undefined; any value in [-1, 1] is valid (PyTorch: 0) 2
    ulp unit in the last place: the gap between adjacent floats 2
    relative L2 error ||a - b|| / ||b|| over the whole tensor; robust accuracy measure 2
    golden files stored reference outputs for fixed inputs 2
    oracle independent implementation used as ground truth 2
    gradcheck compares an analytic gradient with finite differences (float64) 3
    CUDA graph a recorded sequence of kernels replayed with one launch 5

    custom op (torch.library) registering a function so the compiler treats it as one opaque node 5
